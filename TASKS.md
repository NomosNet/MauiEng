# Задачи до рабочего MVP

Рабочий MVP — это офлайн-приложение на Samsung Galaxy Note 9, которым приятно пользоваться одной рукой в метро без интернета. Субтитры разбираются до сборки, не внутри приложения. При первом запуске уже лежат карточки серии с переводом и озвучкой, фразы для проговаривания, а чтение и просмотр открывают `martiniden.pdf` и серию Gravity Falls S01E01 без субтитров. Критерий готовности: на этом готовом материале закрывается весь день, данные переживают перезапуск, виджет показывает то же, что экран «Сегодня», а интерфейс выглядит цельным, а не как шаблон MAUI.

Уже есть в коде и заново писать не нужно: SQLite (`mauieng.db`), SM-2, четыре блока дня, серия, экраны «Сегодня / Занятие / Колоды / Проговаривание / Новое слово / Новая фраза», переворот карточки по оси Y, TTS, виджет Android. Колоду «Базовые слова» из 24 слов в первой версии заменяет готовый набор серии. Ниже — то, что ещё мешает назвать это рабочим.

Вне MVP, как в README: импорт `.xlsx`, достижения, экран настроек.

## 1. Сборка и установка

- [ ] `dotnet test` проходит.
- [ ] `dotnet build src/MauiEng/MauiEng.csproj -f net10.0-android` проходит.
- [ ] `dotnet build src/MauiEng/MauiEng.csproj -f net10.0-windows10.0.19041.0` проходит. Окно ~420×860 годится только для макета.
- [ ] Сборка ставится на Note 9 по USB (режим разработчика). Повторный запуск не создаёт вторую базу и не затирает прогресс.

## 2. Первый запуск без сети

- [ ] В авиарежиме приложение открывается и само создаёт `mauieng.db`. На «Колодах» сразу есть колода серии: слова с переводом, транскрипцией и примером, все due сегодня. Отдельно собирать колоду или разбирать субтитры в приложении не нужно.
- [ ] В «Проговаривании» уже есть короткие фразы серии. Экран не пустой.
- [ ] Экран «Сегодня»: серия 0, план `0 / 4`, блок карточек показывает `0/20` и число слов серии, которые ждут повторения.

## 3. Карточки

- [ ] С «Сегодня» открывается колода слов серии. С вкладки «Колоды» открывается выбранная колода, и в очереди только её due-слова. «Базовые слова» в этот проход не подмешиваются.
- [ ] Лицо: метка «Новое» / «Короткая память» / «Долгая память» и английское слово. Тап переворачивает по оси Y. Оборот: перевод, транскрипция, пример.
- [ ] «Помню»: первый успех — через 1 день, второй — через 3, дальше интервал × лёгкость (старт 2.5). «Не помню»: интервал 1 день, лёгкость −0.2, не ниже 1.3, карточка в конец текущей очереди.
- [ ] «Не помню» остаётся в сегодняшней очереди, даже если уйти с экрана и открыть занятие снова. Сейчас ответ сразу пишет `due` на завтра, и после пересоздания страницы карточка пропадает из очереди.
- [ ] Блок «Карточки» закрывается после 20 ответов или когда очередь пуста. Пока в очереди ещё лежат карточки «Не помню», блок не становится «Готово» только из-за того, что в базе у них уже завтрашняя дата.
- [ ] Кнопка «Звук» читает слово первой английской локалью (en-US / en-GB). Если голоса нет, занятие не падает и на экране есть короткая пометка, что озвучки нет. Сейчас ошибка TTS глотается молча.

## 4. Готовый материал для проверки

Субтитры разбираются заранее, один раз, до того как приложение попадает на телефон. В MVP нет шага «импортировать srt». После установки уже можно нажимать все четыре блока.

Источник слов и фраз — `Gravity Falls - S01xE01 - Tourist Trapped-en.srt`. Книга и серия остаются файлами на телефоне, в apk их не кладут:

- Чтение: `martiniden.pdf`
- Сериал: `Gravity Falls S01 E01 - Tourist Trapped (1080p) English.mp4`

Порядок дня: сначала готовые карточки, потом эта же серия без текста на экране. Услышанное в эпизоде закрепляет перевод, который уже был на обороте.

- [ ] Из субтитров отобран набор слов на одно занятие и запас сверх 20 повторов. Служебные слова (`the`, `a`, `to`, `and` и такие же) не входят. Имена говорящих и реплики, где только звук в скобках (`( Screaming )`), не входят.
- [ ] У каждой карточки заранее заполнены английское слово, русский перевод, транскрипция и пример — живая реплика серии, уже без `Dipper:` и прочего имени. Пустых оборотов нет.
- [ ] Рядом лежит короткий список фраз той же серии для блока «Проговаривание»: фраза по-английски и перевод. Их хватает, чтобы пройти блок и услышать озвучку.
- [ ] Этот набор — сид базы при первом запуске, колода серии на экране «Колоды». Повторный запуск сид не дублирует и не затирает ответы SM-2.
- [ ] «Звук» на карточке читает слово, «Сказать» на проговаривании читает фразу. Озвучка — системный TTS, отдельные аудиофайлы не качаются.
- [ ] «Чтение» открывает `martiniden.pdf`, «Сериал» открывает mp4. Оба пути помнятся после перезапуска. Сейчас в базу пишется `FullPath` от `FilePicker`: на Android это часто временная копия. Нужен сохранённый content URI с постоянным разрешением.
- [ ] Серия открывается без субтитров: на экране нет текста реплик. Приложение передаёт плееру только mp4. Если плеер сам подхватывает любой `.srt` из той же папки, видео всё равно идёт без надписей.
- [ ] «Готово» закрывает блок «Чтение» или «Сериал» и обновляет `N / 4`. Ручное «Добавить слово» и «Добавить фразу» остаётся, но для проверки дня оно не нужно: материал уже в базе.

## 5. Проговаривание

- [ ] Экран с первого запуска показывает готовые фразы серии с переводом. «Готово» закрывает блок и без новых фраз, добавленных вручную.
- [ ] «Сказать» произносит фразу системным TTS. Нет английского голоса — без падения, с той же пометкой, что у карточек.
- [ ] «Готово» закрывает блок и возвращает на «Сегодня».

## 6. Серия

Огонёк растёт только когда за день закрыты все четыре блока. Вчерашний полный день ещё держит серию. Пропуск раньше, чем вчера, обнуляет её.

- [ ] Четыре «Готово» за сегодня дают серию 1 и `goal_met` в `day_log`. Три блока серию не увеличивают.
- [ ] Поведение границы дней совпадает с `StudyStreak`: вчера есть, сегодня ещё нет — серия жива; дырка раньше вчера — серия 0. На телефоне это проверяется сменой даты, юнит-тесты `StudyStreakTests` при этом зелёные.

## 7. Виджет «MauiEng — Сегодня»

- [ ] Виджет есть в галерее виджетов Android и ставится на домашний экран.
- [ ] На нём видны огонёк и число дней, прогресс `N / 4`, четыре подписанные метки блоков (не просто `● ○ ○ ○` без подписи) и сколько карточек ждут повторения.
- [ ] Тап открывает приложение.
- [ ] После ответа на карточку или «Готово» виджет обновляется без перезагрузки телефона. Значения совпадают с экраном «Сегодня».

## 8. Экран Note 9

Ориентир — 1440×2960, высокий формат.

- [ ] «Сегодня» прокручивается целиком: огонёк, `N / 4`, четыре блока, кнопки не обрезаны.
- [ ] Крупный текст карточки и кнопки «Не помню» / «Помню» читаются одной рукой, без горизонтальной прокрутки.
- [ ] Клавиатура на «Новое слово» и «Новая фраза» не закрывает поле и кнопку «Сохранить» (`AdjustResize` уже задан — проверить на устройстве).
- [ ] Светлая и тёмная тема системы не оставляют белый текст на белом и чёрный на чёрном.

## 9. Удобство и внешний вид

Сейчас экраны собраны из стандартных кнопок и фиолетовой палитры шаблона MAUI. На Note 9 план дня — длинная колонка одинаковых рамок. Занятие должно ощущаться как колода карточек, а не как форма.

### Пользование одной рукой

- [ ] На «Сегодня» за один взгляд видно, сколько блоков осталось. Закрытый блок визуально гаснет: галочка, приглушённый текст, кнопки выбора файла и «Готово» не спорят с уже сделанным.
- [ ] У каждого блока одна главная кнопка в зоне большого пальца: «Заниматься», «Открыть», «Проговаривать». «Выбрать книгу», «Выбрать видео», «Добавить слово» и «Добавить фразу» — второстепенные, не четыре одинаковые залитые кнопки.
- [ ] «Не помню» и «Помню» стоят внизу экрана, крупные, разного цвета. «Не помню» не выглядит как основная кнопка.
- [ ] На проговаривании «Сказать» — большая цель: фразу можно произнести, не целясь в узкую кнопку справа.
- [ ] Длинное имя книги или видео обрезается в одну строку и не раздувает карточку блока.
- [ ] Ошибки («сначала выберите книгу», «нет озвучки») появляются рядом с действием, коротко, без простыни текста сверху экрана.
- [ ] Пустые состояния спокойные и говорят, что на сегодня уже всё сделано. Первый запуск сам по себе пустым не бывает: колода и фразы уже на месте.
- [ ] Закрытие блока — один тап, без диалога подтверждения. Переход «Сегодня → занятие → назад» не теряет место в списке и не мигает пустым экраном.
- [ ] Поля «Новое слово» и «Новая фраза» идут сверху вниз в порядке заполнения. «Сохранить» остаётся на виду, когда открыта клавиатура.

### Как это выглядит

- [ ] Одна палитра на всё приложение и виджет: спокойный фон, один акцент, отдельный цвет для «Помню» и для «Не помню». Светлая и тёмная тема используют одни и те же роли цветов. Шаблонный фиолетовый `#512BD4` и синяя иконка `#236AE0` сходятся в одну гамму.
- [ ] Общие отступы, скругление и три размера текста: заголовок, основной, подпись. Размеры не задаются заново на каждом экране.
- [ ] Карточка слова — одна поверхность с воздухом вокруг слова. Лицо и оборот совпадают по размеру, переворот не прыгает. Подсказка «нажмите, чтобы перевернуть» не спорит со словом.
- [ ] Четыре блока дня — один и тот же вид с состояниями «ещё нет» и «готово», а не четыре разные стопки кнопок.
- [ ] Когда план `4 / 4`, огонёк и подпись серии заметно отличаются от нулевого дня. Без отдельного экрана достижений.
- [ ] Иконка, сплэш и вкладки «Сегодня» / «Колоды» из той же гаммы. У вкладок понятное выбранное состояние.
- [ ] Виджет выглядит как кусок того же приложения: те же цвета, читаемые подписи блоков, без чужого синего прямоугольника.
- [ ] Анимация только у переворота карточки, короткая. Ответ «Помню» / «Не помню» сменяется следующей карточкой сразу, без лишнего движения.

## Готово, когда

В авиарежиме на Note 9, сразу после установки: колода серии уже с переводом, транскрипцией, примером и озвучкой, фразы уже в «Проговаривании». За один проход — 20 таких карточек, затем `Gravity Falls S01 E01 - Tourist Trapped (1080p) English.mp4` без субтитров, `martiniden.pdf` открывается повторно, готовые фразы произнесены вслух. Все четыре блока закрыты, серия стала 1, виджет показывает `4 / 4`. После перезапуска прогресс, книга и видео на месте, карточки не задвоились. Проход делается одной рукой, закрытые блоки видно без чтения каждой кнопки, экраны и виджет выглядят как одно приложение.
