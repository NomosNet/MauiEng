# MauiEng

Приложение на C# и .NET MAUI для изучения английского на Samsung Galaxy Note 9. Карточки, ежедневный план, озвучка и огонёк серии работают **офлайн** — без интернета, в метро и трамвае.

Словарь, прогресс и план дня лежат в **SQLite на телефоне**. Книги и видео хранятся отдельно: приложение открывает выбранные локальные файлы и отмечает блоки плана.

Экран Note 9 — 1440×2960. Интерфейс рассчитан на высокий формат.

## Возможности

### Ежедневный план

На экране «Сегодня» четыре блока:

1. **Карточки** — 10–15 минут повторений (SM-2). Блок закрывается после 20 повторов или когда на сегодня нечего повторять.
2. **Чтение** — открыть локальную книгу, выписать слова, отметить «Готово».
3. **Сериал** — открыть локальное видео, выписать фразы, отметить «Готово».
4. **Проговаривание** — фразы вслух через системный TTS, затем «Готово».

Огонёк серии растёт, когда **все четыре блока** закрыты за день. Пропуск раньше вчерашнего дня обнуляет серию.

### Карточки слов

Обычные страницы на XAML. По нажатию карточка переворачивается по оси Y: на лицевой стороне английское слово, на обороте перевод, транскрипция и пример.

### Словарь в SQLite

База создаётся при первом запуске в каталоге приложения (`mauieng.db`). Если колод ещё нет, добавляется колода «Базовые слова» из 24 слов. Подключение к серверу не нужно.

### Озвучка

Встроенный API MAUI, без скачанных аудиофайлов. Берётся первая английская локаль системы (en-US / en-GB). Если голоса нет, занятие продолжается без озвучки.

### Интервальное повторение

Упрощённый SM-2: лёгкость, интервал в днях, дата следующего показа.

- **Не помню** — интервал 1 день, лёгкость −0.2 (не ниже 1.3), карточка в конец очереди.
- **Помню** — первый успех 1 день, второй 3 дня, дальше интервал × лёгкость (старт 2.5).

На карточке: «Новое», «Короткая память», «Долгая память».

### Виджет Android

Виджет «MauiEng — Сегодня» на домашний экран:

- огонёк и серия дней
- прогресс плана `N / 4`
- метки четырёх блоков
- сколько карточек ждут повторения

Тап открывает приложение. Обновляется при изменении прогресса (офлайн).

### Импорт Excel и достижения

Пока не входят в приложение. Позже: `.xlsx` через MiniExcel и экран достижений.

## Стек

- C#, .NET 10, .NET MAUI, XAML
- `Microsoft.Data.Sqlite` — локальная база
- CommunityToolkit.Mvvm — состояние экранов
- `Microsoft.Maui.Media.TextToSpeech` — озвучка
- Android AppWidget — домашний виджет статистики
- Android и Windows. Ориентир телефона — Samsung Galaxy Note 9

## Экраны

1. **Сегодня** — огонёк, чеклист плана, выбор книги/видео.
2. **Занятие** — карточка, переворот, озвучка, «Не помню» / «Помню».
3. **Колоды** — список колод и due.
4. **Проговаривание** — фразы и TTS.
5. **Новое слово / Новая фраза** — быстрый ввод из книги или сериала.
6. **Импорт / Достижения / Настройки** — ещё нет.

## Данные

- **deck** — колода
- **word** — слово
- **review** — прогресс SM-2
- **day_log** — день, число повторов, закрыт ли полный план (`goal_met`)
- **day_task** — статус четырёх блоков дня
- **media_link** — путь к книге и видео
- **phrase** — фразы для проговаривания

## Сборка

Проекты: `src/MauiEng.Core`, `src/MauiEng`, `tests/MauiEng.Tests`.

```bash
dotnet test
dotnet build src/MauiEng/MauiEng.csproj -f net10.0-android
dotnet build src/MauiEng/MauiEng.csproj -f net10.0-windows10.0.19041.0
dotnet build src/MauiEng/MauiEng.csproj -t:Run -f net10.0-android
dotnet build src/MauiEng/MauiEng.csproj -t:Run -f net10.0-windows10.0.19041.0
```

На Windows окно ~420×860 для проверки макета. На Note 9 — режим разработчика и отладка по USB. Интернет для работы приложения не нужен; виджет добавляется из галереи виджетов Android.
