# MauiEng

Приложение на C# и .NET MAUI для изучения английских слов на Samsung Galaxy Note 9. Словарь, карточки, озвучка и прогресс хранятся на телефоне и работают без сервера.

Экран Note 9 — 1440×2960. Интерфейс рассчитан на этот высокий формат: крупная карточка, кнопки ответа внизу, список колод и достижения на отдельных экранах.

## Возможности

### Карточки слов

Обычные страницы на XAML. По нажатию карточка переворачивается анимацией `RotateYTo`: на лицевой стороне английское слово, на обороте перевод, транскрипция и пример.

### Словарь в SQLite

Локальная база через пакет `sqlite-net-pcl`. В ней лежат слова, колоды, расписание повторений, дневная статистика и достижения. Доступ к словарю быстрый, настройка сводится к одному файлу базы в хранилище приложения.

### Озвучка

Встроенный API MAUI, без скачанных аудиофайлов:

```csharp
await TextToSpeech.Default.SpeakAsync("Hello", new SpeechOptions
{
    Locale = await PickEnglishLocaleAsync()
});
```

Телефон сам читает слово. В настройках выбирается английская локаль, которую отдаёт система (например, en-US или en-GB).

### Интервальное повторение

Упрощённый SM-2 на чистом C#. У каждой карточки есть лёгкость (`Ease`), интервал в днях и дата следующего показа.

- **Не помню** — интервал возвращается к 1 дню, лёгкость немного снижается, карточка снова попадает в сегодняшнюю очередь.
- **Помню** — интервал растёт: первый успех 1 день, второй 3 дня, дальше интервал умножается на лёгкость (старт 2.5).

На экране это выглядит как колоды Лейтнера: новое слово, короткая память, долгая память. Внутри считается одна и та же формула SM-2.

### Занятия каждый день и достижения

Как в Duolingo: дневная цель, серия дней и список достижений.

- Дневная цель — число повторённых карточек (по умолчанию 20). Цель можно поменять в настройках.
- Серия растёт, если цель закрыта сегодня. Пропуск дня обнуляет серию.
- Достижения открываются по событиям и остаются в профиле: первое слово, первая неделя серии, 100 и 500 повторений, первая импортированная колода, семь дней подряд с закрытой целью.

Главный экран показывает серию, прогресс цели на сегодня и кнопку «Заниматься».

### Импорт таблиц Excel

В приложение загружается файл `.xlsx`. Первая строка — заголовки, дальше слова. Колонки:

| Колонка | Обязательная | Смысл |
| --- | --- | --- |
| Word | да | Английское слово или фраза |
| Translation | да | Перевод |
| Transcription | нет | Транскрипция |
| Example | нет | Пример |
| Deck | нет | Название колоды. Пустое значение — колода «Импорт» |

Файл читается через MiniExcel, строки пишутся в SQLite и сразу доступны в карточках. Повторный импорт того же слова в ту же колоду обновляет перевод и пример, прогресс повторения сохраняется.

## Стек

- C#, .NET MAUI, XAML — интерфейс и анимация карточки
- `sqlite-net-pcl` — локальная база
- `Microsoft.Maui.Media.TextToSpeech` — озвучка
- `MiniExcel` — чтение `.xlsx`
- Android, ориентир — Samsung Galaxy Note 9

## Экраны

1. **Сегодня** — серия, цель дня, переход к занятию.
2. **Занятие** — карточка, переворот, озвучка, «Не помню» / «Помню».
3. **Колоды** — список колод, число слов и сколько ждут повторения.
4. **Импорт** — выбор `.xlsx` и отчёт: сколько строк добавлено и обновлено.
5. **Достижения** — открытые и ещё закрытые цели.
6. **Настройки** — дневная цель и локаль озвучки.

## Данные

- **Deck** — колода: название.
- **Word** — слово: термин, перевод, транскрипция, пример, колода.
- **Review** — прогресс SM-2: лёгкость, интервал, число успешных повторов, дата следующего показа.
- **DayLog** — день: дата, сколько карточек повторено, закрыта ли цель.
- **Achievement** — достижение: код, название, момент открытия.

## Сборка

Решение MAUI в этом репозитории ещё не создано. Когда оно появится, запуск на телефоне:

```bash
dotnet build -f net9.0-android
dotnet build -t:Run -f net9.0-android
```

На Note 9 включается режим разработчика и отладка по USB. Приложение ставится как обычный Android-пакет и дальше работает без интернета: словарь, озвучка системным голосом, повторения и достижения остаются на устройстве.
