# MauiEng

Приложение на C# и .NET MAUI для изучения английских слов на Samsung Galaxy Note 9. Карточки, озвучка и повторения работают на телефоне. Словарь и прогресс лежат в PostgreSQL: без доступной базы занятие не открывается.

Экран Note 9 — 1440×2960. Интерфейс рассчитан на этот высокий формат: крупная карточка, кнопки ответа внизу, список колод на отдельном экране.

Первый срез: подключение к базе, экраны «Сегодня», «Занятие» и «Колоды». Импорт Excel, достижения и настройки цели и голоса описаны ниже и в приложение ещё не входят.

## Возможности

### Карточки слов

Обычные страницы на XAML. По нажатию карточка переворачивается по оси Y (`RotateYToAsync`): на лицевой стороне английское слово, на обороте перевод, транскрипция и пример.

### Словарь в PostgreSQL

Приложение подключается к серверу напрямую через Npgsql, без отдельного HTTP API. При первом успешном входе создаются таблицы `deck`, `word`, `review` и `day_log`. Если колод ещё нет, добавляется колода «Базовые слова» из 24 слов.

Сервер и пустую базу нужно создать заранее. На телефоне в поле хоста указывается адрес компьютера в локальной сети, не `localhost`: на Note 9 `localhost` — это сам телефон. В `pg_hba.conf` должен быть доступ с этого адреса, порт 5432 открыт в брандмауэре. Шифрование соединения в этом срезе выключено (`Ssl Mode=Disable`), чтобы телефон мог ходить на локальный сервер без сертификата.

Пароль вводится на экране «Подключение» и сохраняется только в `Preferences` на устройстве.

Пример параметров, без пароля:

- Хост: `localhost` на компьютере, адрес компьютера в сети на телефоне
- Порт: `5432`
- База: `mauieng`
- Пользователь: `postgres`

### Озвучка

Встроенный API MAUI, без скачанных аудиофайлов. Приложение берёт первую английскую локаль, которую отдаёт система (например, en-US или en-GB):

```csharp
await TextToSpeech.Default.SpeakAsync("Hello", new SpeechOptions
{
    Locale = englishLocale
});
```

Если английского голоса нет, занятие продолжается без озвучки. Выбор локали в настройках появится позже.

### Интервальное повторение

Упрощённый SM-2 на чистом C#. У каждой карточки есть лёгкость (`Ease`), интервал в днях и дата следующего показа.

- **Не помню** — интервал возвращается к 1 дню, лёгкость снижается на 0.2, но не ниже 1.3. Карточка снова ставится в конец текущей очереди занятия. В базе срок — завтра.
- **Помню** — интервал растёт: первый успех 1 день, второй 3 дня, дальше интервал умножается на лёгкость (старт 2.5).

На карточке это видно как ящик Лейтнера: «Новое», «Короткая память», «Долгая память». Внутри считается одна и та же формула SM-2.

### Занятия каждый день и достижения

Дневная цель и серия уже на экране «Сегодня». Список достижений в первый срез не входит.

- Дневная цель — 20 повторённых карточек. Поменять её пока нельзя.
- Серия растёт, если цель закрыта сегодня. Если цель закрыта вчера, а сегодня ещё нет, серия сохраняется. Пропуск раньше вчерашнего дня обнуляет серию.
- Позже достижения будут открываться по событиям и оставаться в профиле: первое слово, первая неделя серии, 100 и 500 повторений, первая импортированная колода, семь дней подряд с закрытой целью.

Главный экран показывает серию, прогресс цели на сегодня и кнопку «Заниматься».

### Импорт таблиц Excel

В первый срез не входит. Когда появится, в приложение будет загружаться файл `.xlsx`. Первая строка — заголовки, дальше слова. Колонки:

| Колонка | Обязательная | Смысл |
| --- | --- | --- |
| Word | да | Английское слово или фраза |
| Translation | да | Перевод |
| Transcription | нет | Транскрипция |
| Example | нет | Пример |
| Deck | нет | Название колоды. Пустое значение — колода «Импорт» |

Файл будет читаться через MiniExcel, строки — записываться в PostgreSQL и сразу открываться в карточках. Повторный импорт того же слова в ту же колоду обновляет перевод и пример, прогресс повторения сохраняется.

## Стек

- C#, .NET 10, .NET MAUI, XAML — интерфейс и анимация карточки
- Npgsql — доступ к PostgreSQL
- CommunityToolkit.Mvvm — состояние экранов
- `Microsoft.Maui.Media.TextToSpeech` — озвучка
- Android и Windows. Ориентир телефона — Samsung Galaxy Note 9

## Экраны

1. **Подключение** — хост, порт, база, пользователь и пароль.
2. **Сегодня** — серия, цель дня, переход к занятию.
3. **Занятие** — карточка, переворот, озвучка, «Не помню» / «Помню».
4. **Колоды** — список колод, число слов и сколько ждут повторения.
5. **Импорт** — ещё нет. Выбор `.xlsx` и отчёт: сколько строк добавлено и обновлено.
6. **Достижения** — ещё нет. Открытые и закрытые цели.
7. **Настройки** — ещё нет. Дневная цель и локаль озвучки.

## Данные

- **deck** — колода: название.
- **word** — слово: термин, перевод, транскрипция, пример, колода.
- **review** — прогресс SM-2: лёгкость, интервал, число успешных повторов, дата следующего показа.
- **day_log** — день: дата, сколько карточек повторено, закрыта ли цель.

Таблица достижений появится вместе с экраном достижений.

## Сборка

Проекты: `src/MauiEng.Core` (формула и серия), `src/MauiEng` (приложение), `tests/MauiEng.Tests`.

```bash
dotnet test
dotnet build src/MauiEng/MauiEng.csproj -f net10.0-android
dotnet build src/MauiEng/MauiEng.csproj -f net10.0-windows10.0.19041.0
dotnet build src/MauiEng/MauiEng.csproj -t:Run -f net10.0-android
dotnet build src/MauiEng/MauiEng.csproj -t:Run -f net10.0-windows10.0.19041.0
```

На Windows окно открывается узким и высоким, около 420×860, чтобы проверить макет телефона. На Note 9 включается режим разработчика и отладка по USB. Приложению нужен доступ к PostgreSQL по сети и разрешение `INTERNET`.
